# art-src

Raw inputs for the art. Nothing here is loaded by the game.

- `dl/` — PixelLab downloads, exactly as they came. Never edit these; finish them in the
  `pixel-art/` scripts.
- `prompts.md` — every PixelLab job: the prompt, the tool, the size, its cost in generations and
  whether it was kept. The running total must stay within the cap in `docs/ART_PLAN.md`.
